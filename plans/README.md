# Animation improvement plans

Generated by the `improve-animations` skill from an audit at commit `f2cc33d`.
Each plan is self-contained: exact file paths, current-code excerpts, and target
values. An executor (any agent or a cheaper model) can implement one plan with no
other context. **Plans only touch motion properties** — no markup/logic changes.

## Plans

| # | Title | Severity | Category | Status |
| --- | --- | --- | --- | --- |
| 001 | Add a motion token scale (easing + duration) | MEDIUM | Cohesion (foundational) | TODO |
| 002 | Add global `prefers-reduced-motion` support | HIGH | Accessibility | TODO |
| 003 | Replace `transition-all` with scoped properties | MEDIUM | Performance / Cohesion | TODO |
| 004 | Replace `ease-linear` on the sidebar | MEDIUM | Easing & duration | TODO |
| 005 | Fix the view-switcher pill label pop | MEDIUM | Physicality / Cohesion | TODO |

## Recommended execution order

1. **001** first — it adds the `--ease-*` / `--duration-*` tokens that 004 and 005
   reference. Nothing visible changes yet.
2. **002** — highest-severity, fully independent. Can land anytime; listed early
   because it's the biggest user-facing win for the smallest diff.
3. **003** — independent of the others (uses only built-in Tailwind utilities).
4. **004** — **depends on 001** (`--ease-drawer`, `--duration-slow`).
5. **005** — **depends on 001** (`--ease-in-out`, `--ease-out`, `--duration-base`).

## Dependencies

```
001 ──┬──> 004
      └──> 005
002  (independent)
003  (independent)
```

002 and 003 can be done in parallel with each other and with 001. 004 and 005
must wait for 001.

## Notes

- Everything is CSS/Tailwind — no JS animation library, no new dependencies.
- The Base UI popovers (dialog, dropdown, select, tooltip, hover-card) already
  animate correctly and were intentionally left out of scope.
- After executing, feel-check each plan's **Verification** section in a browser
  (DevTools Animations panel at 10% speed + `prefers-reduced-motion` emulation),
  not just the build.
- Re-run `improve-animations reconcile` after execution to flip statuses to DONE
  and refresh any drifted `file:line` references.
